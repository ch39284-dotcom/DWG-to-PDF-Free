DWG to PDF guides

Step-by-step answers for every way people convert CAD drawings to PDF — with AutoCAD, without it, in bulk, and on a phone.

dwg to pdf without autocadHow to convert DWG to PDF without AutoCAD+

You don't need a paid AutoCAD licence to get a PDF out of a DWG. Three free routes:

  1. This tool (fastest for DXF): If the sender can send DXF — or you save the DWG as DXF once — drop it in the converter above. Preview, pick a paper size, download the PDF.
  2. Autodesk DWG TrueView (free, Windows): Autodesk's own free viewer. Open the DWG, type PLOT, choose DWG To PDF.pc3, set paper and plot area, and save.
  3. ODA File Converter (free, Win/Mac/Linux): Converts DWG ↔ DXF in batches. Convert DWG to DXF first, then run the DXF through this page for the PDF.

Ask whoever sent the DWG to also export a DXF (SAVEAS → DXF) — it takes them 20 seconds and removes the whole problem.

how to convert dwg to pdf in autocadHow to convert DWG to PDF in AutoCAD (PLOT & DWG To PDF.pc3)+
  1. Open the drawing and type PLOT (or Ctrl+P).
  2. Under Printer/plotter, select DWG To PDF.pc3.
  3. Pick your paper size (A4, A3…) and set Plot area to Extents or Window.
  4. Tick Fit to paper and Center the plot.
  5. Choose a plot style: monochrome.ctb for black & white, or your office CTB for colour.
  6. Click OK, choose a filename and folder — that's your PDF.

Tip: for a one-click repeat, use EXPORTPDF, or save the setup as a Page Setup so every drawing plots identically.

batch convert dwg to pdfBatch convert DWG to PDF+

Got a folder of drawings? Converting one by one wastes an afternoon. Batch is not part of these free single-file tools — the four converters on this page do one file at a time, free. For batches today, use one of these free desktop routes:

  • AutoCAD PUBLISH: Type PUBLISH, add all the drawings/layouts, set output to PDF — AutoCAD writes one PDF (or one per sheet) for the whole set.
  • Sheet Set Manager: Best for project sets — publish the entire sheet set to a single multi-page PDF.
  • ODA File Converter + this tool: Batch-convert the DWG folder to DXF with the free ODA converter, then convert each DXF here. Slower, but completely free with no AutoCAD licence.
  • Core Console scripts: AutoCAD's accoreconsole.exe can run a plot script across hundreds of files unattended — the pro route for very large sets.
how to convert dwg to pdf in mobileHow to convert DWG to PDF on mobile+
  1. On this page: This converter runs in your phone browser. If you have the DXF (from email, WhatsApp or Drive), tap the upload box above, preview, and download the PDF straight to your phone.
  2. AutoCAD mobile app: Open the DWG from cloud storage, use the share/plot options to export a PDF of the current view.
  3. Ask for DXF: On site and someone emails you a DWG? Reply asking for the DXF export too — then step 1 works every time, no app installs.

For viewing only, the free DWG FastView app opens DWG on Android and iOS and can share views as images or PDF.

dwg to pdf black and whiteDWG to PDF in black and white+

Black & white PDFs print cheaper, photocopy cleanly, and are the standard for issued construction drawings.

  • Here: Use the Black & white toggle in the converter — every layer colour is plotted as black on white, exactly like a monochrome plot style.
  • In AutoCAD: In the PLOT dialog, set the plot style table to monochrome.ctb. All colours map to black; line weights still come from the drawing.
  • Watch out: Yellow and light-cyan layers print almost invisibly in colour but perfectly in monochrome — one more reason B&W is the safe default for sharing.
what is dwg to pdf pc3What is DWG To PDF.pc3?+

A .pc3 file is an AutoCAD plotter configuration file — a saved set of settings for one output device. DWG To PDF.pc3 is the one Autodesk ships with AutoCAD: a virtual printer that "prints" your drawing into a vector PDF file instead of onto paper.

  • It supports custom paper sizes, layer export to PDF, and font embedding.
  • Companions you'll see in the list: AutoCAD PDF (General Documentation).pc3, AutoCAD PDF (High Quality Print).pc3 and AutoCAD PDF (Smallest File).pc3 — same idea, different quality/size trade-offs.
  • If it's missing from your plotter list, add it via PLOTTERMANAGER → Add-A-Plotter Wizard → Autodesk ePlot (PDF).

Frequently asked questions

Straight answers to the questions people actually search for.

How to save DWG to PDF?+

In AutoCAD: type PLOT, choose DWG To PDF.pc3, set paper size and plot area, click OK and save. Without AutoCAD: save or export the file as DXF and use the free converter at the top of this page — upload, preview, download. No signup either way.

How to export DWG to PDF — is it different from plotting?+

Not really. "Export", "save as PDF", "print to PDF" and "plot to PDF" all produce the same thing: a PDF of your drawing. AutoCAD even has a dedicated EXPORTPDF command that uses your current page setup. This page uses the same idea for DXF files — the PDF is written from the drawing's vector geometry.

How to print DWG to PDF?+

"Printing" to PDF means choosing a virtual PDF printer instead of a physical one. In AutoCAD that's DWG To PDF.pc3 in the PLOT dialog. In any Windows app you can also use Microsoft Print to PDF — but for CAD files the pc3 route keeps layers and line weights correct, so prefer it.

What is the best DWG to PDF converter online free?+

It depends on your file. For DXF, a browser converter like this one is best: free, instant, private (the file never leaves your device) and no install. For native DWG, no purely-browser tool can read the closed format — the best free options are Autodesk's own DWG TrueView on desktop, or converting DWG → DXF with the free ODA File Converter and then using this page. Be wary of "free DWG converters" that demand an email before showing your file.

DWG to PDF vs AutoCAD PDF — what's the difference?+

They're the same output, made by different drivers. DWG To PDF.pc3 is AutoCAD's original PDF driver. Newer AutoCAD versions add the "AutoCAD PDF" .pc3 presets (General Documentation, High Quality Print, Smallest File, Web and Mobile) with finer control over resolution and file size. PDFs from this page are standard vector PDFs too — any of them opens in every PDF reader, prints the same, and zooms without pixelating.

How can I convert PDF to DWG for free?+

Use the PDF to DXF tool above: upload a vector PDF (one plotted from CAD software, not a scan), and it extracts the line geometry into an editable DXF. Open that DXF in AutoCAD, BricsCAD or the free LibreCAD and choose Save As → DWG — that's your native DWG, completely free. Text in the PDF is not rebuilt as CAD text; the linework is what converts.

How do I convert DWF to PDF for free?+

Use the DWF to PDF tool above. DWFx files — the ZIP/XML-based DWF Autodesk has published since 2008 — convert fully in your browser, with multi-sheet files stacked onto one tall PDF page. Older classic binary DWF files can't be read by a browser; open those in the free Autodesk Design Review and print to PDF, or re-publish them as DWFx from AutoCAD.

How do I convert DWG to JPG or PNG for free?+

Use the DWG to JPG/PNG tool above: load the DXF (save a native DWG as DXF first), pick PNG for the crispest image or a transparent background, or JPG for a smaller file, choose 1×, 2× or 3× resolution and download. 2× PNG is the sweet spot for WhatsApp and slides.

Is batch conversion free too?+

Not in these tools — all four converters here are free for one file at a time, with no limit on how many times you use them. Converting a whole folder at once is the feature paid tools charge for. Until then, the batch guide above shows the free desktop routes: AutoCAD PUBLISH and the free ODA File Converter.

Is this converter really free? Any limits or signup?+

Yes — this is the free version and there is no Pro plan, no signup, no watermark and no payment. Because DXF conversion happens on your own device, there's no server cost to recover, so there's nothing to charge for. Very large files are limited only by your device's memory.

Is my drawing uploaded or stored anywhere?+

No — in all four tools. Your DXF, PDF or DWFx is read by JavaScript in this browser tab, drawn to the preview, and the output file is generated locally. Close the tab and it's gone. That's also why the tools work offline once the page has loaded.

How do I convert DWG to PDF in black and white?+

Here: load the drawing and switch the colour mode to Black & white before downloading. In AutoCAD: set the plot style to monochrome.ctb in the PLOT dialog. See the full guide above.
